# 作業BGM動画 仕様書

## 概要
車の3Dクレイモデルを(0,0)に固定し、カメラがX軸方向にスライドして車側面を映す1分間の動画（1台分）を生成するプログラム。
ユーザーは複数台の動画を後からFinal Cut Pro等で繋いでコレクション動画を作成する想定。


---

## 1. 動画基本仕様

| 項目 | 仕様 |
|------|------|
| 解像度 | 1920×1080 (フルHD / 1080p) |
| アスペクト比 | 16:9 横長 |
| フレームレート | 30 FPS |
| 動画長さ | 60秒（1800フレーム、1台分） |
| 出現/消失演出 | なし（突然現れて、スライドして消える） |

---

## 2. 世界・環境設定

### 背景
- 真っ黒な背景（背景色: 黒 #000000）
- ネオン発光の3Dグリッド床面

### グリッド床
- サイズ: 1m四方のマス目、全長100m (Y=-50m ~ Y=+50m)
- 幅: X±15m
- 色: シアン色（エミッション発光、strength=6.0）
- 右端から左端へのスライド用床面として配置

### クレイモデル
- 色: **ミディアムグレー**（RGB: 0.65, 0.65, 0.65 / テクスチャなしのクレイ調、博物館展示風）
- 粗さ (Roughness): 0.45
- メタリック: 0.0

### クレイモデルの配置
- 車は原点(0,0)に固定配置
- 車の向き: Yマイナス方向を向く（X軸で90度回転）
- 動かない・スライドしない

---

## 3. カメラ演出

| 項目 | 仕様 |
|------|------|
| カメラ高さ | 1.7m（人の視点） |
| 移動方法 | X軸方向にスライド（X=-７m → X=+７m） |
| Y座標 | -9m固定 |
| アングル | 常にYプラス方向をまっすぐ見る（パン・チルトなし） |
| 画角 | 35mmレンズ |

### カメラ位置の詳細
- X座標: -7m → +7m（60秒かけてスライド）
- Y座標: -9.5m固定
- Z座標: 1.7m固定
- 向き: Yプラス方向へX軸で3°下げる（X軸回転=π/2 + 3°、少し床を見る角度）

---

## 4. テロップ表示

### 車名表示
- **位置**: 床面・車の前方（車のY座標-3m、高さZ=0.01m）
- 回転: なし（rotation_euler = (0.0, 0.0, 0.0) / Blenderの3Dテキストデフォルト向きで正しく表示される）
- スタイル: 薄いシアン色発光文字（エミッションマテリアル、極薄の厚み）
- 色: (0.5, 1.0, 1.0, 1.0)
- Extrude: 0.005（極薄）
- 配置: 車に親設定しない（どちらも固定なので不要）
- フォント: Meiryo Bold (`mebold.ttc`)

### テロップの表示タイミング
- 動画開始から最後まで常に表示

---

## 5. ライティング

| 項目 | 仕様 |
|------|------|
| 基本照明 | 3ポイントライティング（キーライト、フィラーライト、バックライト） |
| キーライト | SUNライト、エネルギー2.0、右斜め上から照射 |
| フィラーライト | SUNライト、エネルギー1.0、左側から補助 |
| バックライト | SUNライト、エネルギー1.2、後方から輪郭光 |
| 雰囲気 | 博物館展示風、ソフトな陰影 |
| 発光要素 | グリッド床、車名テロップ |

### short-s由来の追加照明
- 各車に追従するAREAライトを親設定（エネルギー200、サイズ3）
- 車の上部3m位置から照射

## 6. 車種データ管理

### データソース
- cars.db (SQLite) から車種情報を1台読み込み
- 必要な情報: `id`, `name`, `glb_filename`

### 設定ファイル
- JSON形式の設定ファイルで、以下の情報を定義:
  - GLBファイルへのパス
  - 車名表示テキスト
  - スライド速度（オプション）

---

## 7. ファイル構成

```
bgm_config.py                   # 設定パラメータ（車ID、GLBパス、FPS等）
bgm_core.py                     # 核心機能（シーン構築・カメラ・アニメーション・レンダリング）
bgm_main.py                     # メインパイプライン（各ステップを順番実行）
run_bgm.py                      # Blenderランチャー
```

### 各ファイルの役割
- **bgm_config.py**: CAR_ID、GLB_DIRECTORY、FPS、DURATION_SECONDS等
- **bgm_core.py**: 車データ読み込み、スケール調整、カメラ/アニメーション/レンダリング設定
- **bgm_main.py**: シーン初期化→グリッド床→ライティング→車インポート→クレイ適用→カメラ→ラベル→アニメーション→レンダリング設定の順に実行
- **run_bgm.py**: Blender CLI経由でbgm_main.pyを起動（--renderフラグ対応）

---

## 8. アニメーションタイムライン

| フレーム | 秒数 | 内容 |
|----------|------|------|
| 0 | 0:00 | カメラがX=-7m位置から開始。車は(0,0)固定 |
| 1-1799 | 0.03s-59.96s | カメラがX軸方向にスライド（-7m → +7m） |
| 1800 | 60:00 | カメラがX=+7m位置に到達。動画終了 |

### スライド速度計算
```python
FPS = 30
TOTAL_SECONDS = 60
TOTAL_FRAMES = FPS * TOTAL_SECONDS  # 1800フレーム
SLIDE_DISTANCE = 14.0  # m (X=-7m → X=+7m)
SPEED_PER_SECOND = SLIDE_DISTANCE / TOTAL_SECONDS  # 0.233m/s
SPEED_PER_FRAME = SLIDE_DISTANCE / TOTAL_FRAMES    # 0.00778m/フレーム
```

## 10. テンプレート構造

`bgm_config.py`に変数定義を置き、以下を書き換えるだけで他の車種にも使い回せるようにする:

```python
# 車種設定
CAR_ID = "2"                          # cars.csvのID
GLB_DIRECTORY = r"C:\3d\Modly\glb"    # GLBファイル所在ディレクトリ

# 動画設定
FPS = 30
DURATION_SECONDS = 60
TOTAL_FRAMES = FPS * DURATION_SECONDS  # 1800
```

## 11. 設定方法

### 11.1 基本設定 (`bgm_config.py`)

動画生成前に、[`bgm_config.py`](bgm_config.py) を編集して以下のパラメータを設定してください。

| パラメータ | 説明 | デフォルト値 | 例 |
|-----------|------|-------------|-----|
| `CAR_ID` | cars.csv に登録されている車のID | `"2"` | `"1"`, `"3"`, `"5"` |
| `GLB_DIRECTORY` | GLBファイルがあるディレクトリのパス | `r"C:\3d\Modly\glb"` | `r"C:\models\glb"` |
| `FPS` | フレームレート | `30` | `24`, `60` |
| `DURATION_SECONDS` | 動画の長さ（秒） | `60` | `30`, `90` |
| `TOTAL_FRAMES` | 総フレーム数 (自動計算) | `FPS * DURATION_SECONDS` | 変更不要 |
| `START_Y` | カメラスライド開始位置(Y軸) | `40.0` | `50.0` |
| `END_Y` | カメラスライド終了位置(Y軸) | `-40.0` | `-50.0` |
| `CAMERA_X_OFFSET` | カメラのX軸オフセット | `5.0` | `7.0` |
| `CAMERA_HEIGHT` | カメラの高さ(Z軸) | `1.7` | `1.2` |

**設定手順:**
1. VS Code で [`bgm_config.py`](bgm_config.py) を開く
2. 生成したい車の `CAR_ID` と `GLB_DIRECTORY` を編集する
3. ファイルを保存する

```python
# 例: 車ID="5" の車を再生成する場合
CAR_ID = "5"                          # ← ここを変更
GLB_DIRECTORY = r"C:\3d\Modly\glb"    # GLBの場所が違う場合は変更
FPS = 30
DURATION_SECONDS = 60
TOTAL_FRAMES = FPS * DURATION_SECONDS
START_Y = 40.0
END_Y = -40.0
CAMERA_X_OFFSET = 5.0
CAMERA_HEIGHT = 1.7
```

### 11.2 車の追加・管理

新しい車を比較対象に追加する場合は、以下の手順に従ってください。

1. **GLBファイルの配置**: GLBファイルを `GLB_DIRECTORY` で指定したディレクトリに配置する
2. **CSVへの登録**: [`cars.csv`](cars.csv) に車情報を追加する（必須列: `id`, `name`, `glb_filename`, `全長`, `全幅`, `全高`）
3. **設定の変更**: [`bgm_config.py`](bgm_config.py) の `CAR_ID` を変更して対象車を指定する

### 11.3 Blenderパスの確認

[`run_bgm.py`](run_bgm.py:10) の `BLENDER_PATH` が、お使いの環境のBlenderの実行ファイルと一致していることを確認してください。

```python
# デフォルト設定
BLENDER_PATH = r"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
```

インストール先が異なる場合は、このパスを編集してください。

## 12. 実行方法

### 12.1 GUIモード（シーン確認用）

BlenderのGUIウィンドウを開き、シーンの構成やアニメーションを視覚的に確認します。

```bash
python run_bgm.py
```

**用途:**
- アニメーションの動きを確認する場合
- カメラ位置やライティングを調整したい場合
- デバッグ用

### 12.2 レンダリングモード（動画出力用）

バックグラウンドでBlenderを実行し、MP4動画を自動生成します。

```bash
python run_bgm.py --render
```

**出力:**
- ファイル: `bgm_output.mp4`
- 場所: `~/Desktop/` (デスクトップ)
- フォーマット: MP4 (H.264, 1920×1080, 30fps)

### 12.3 実行手順（まとめ）

1. **設定を編集する**: [`bgm_config.py`](bgm_config.py) を開き、`CAR_ID` と `GLB_DIRECTORY` を確認・変更する
2. **GUIで確認する** (オプション): `python run_bgm.py` を実行し、シーンが正しく構築されることを確認する
3. **レンダリングを実行する**: `python run_bgm.py --render` を実行して動画を生成する
4. **出力を確認する**: デスクトップに出力された `bgm_output.mp4` を再生して確認する

### 12.4 エラー対処

| エラー内容 | 解決方法 |
|-----------|---------|
| `Blenderが見つかりません` | [`run_bgm.py`](run_bgm.py:10) の `BLENDER_PATH` を正しいパスに変更 |
| `スクリプトが見つかりません` | カレントディレクトリがプロジェクト直下であることを確認 |
| GLB読み込み失敗 | `GLB_DIRECTORY` と `cars.csv` の `glb_filename` が正しく設定されているか確認 |
| レンダリングが遅い | `DURATION_SECONDS` を短くするか、BLENDER_EEVEEの設定を調整する |
