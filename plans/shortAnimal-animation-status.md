## 3. 半透明化のドライバー式単一化（✅ 完了）

### 修正内容

**問題**: `_setup_transparency_animation()` を2回呼び出すと、2回目のドライバーが1回目を上書きする。

**修正案**:
- 単一の driver expression に統合
- 式: `0.35 + 0.65 * clamp((frame - 0) / 36.0, 0.0, 1.0) if frame < 216 else 1.0 - 0.65 * clamp((frame - 216) / 72.0, 0.0, 1.0)`
- `animation_settings_shortAnimal.py` の 375-385行目 に直接ドライバー設定コードを記載
