# シーン11 回転アニメーション実装メモ

## 概要

シーン11（フレーム1752-1992）では、2台の車が最小回転半径で右回り1週するアニメーションを実装している。Empty親オブジェクト手法を使用し、車は常に進行方向を向いたまま円を描くように移動する。

## 実装方法

### Empty親オブジェクト手法

1. **回転中心にEmptyを作成**
   - `CarA_TurnPivot` / `CarB_TurnPivot` を各車の回転中心位置に配置
   - 回転中心 = 車の位置 - 最小回転半径（-X方向）

2. **車をEmptyの子オブジェクトにする**
   - 車のローカル位置を `(R, 0, 0)` に設定（R = 最小回転半径）
   - これにより、車はEmptyの右側に配置され、回転開始位置になる
   - 車のZ回転を `π/2`（+90度）に設定して+Y方向を向くようにする

3. **EmptyのZ軸回転にキーフレームを設定**
   - 右回り1週 = `-2π` ラジアン（-360度、時計回り）
   - 25分割で滑らかにアニメーション

## 重要な発見: GLBモデルのデフォルト向き

### 問題と解決までの経緯

初回の実装では、車のZ回転を `-math.pi/2` (-90度) に設定し、車を `(-R, 0)` に配置したが、車が後進するように見えてしまった。その後、以下の試行錯誤を行った:

| 試行 | Empty回転 | 車配置 | 車Z回転 | 結果 |
|------|----------|--------|---------|------|
| 1 | -2π (-Z) | (-R, 0) | -π/2 | 後進 |
| 2 | -2π (-Z) | (-R, 0) | 0 | 後進 |
| 3 | -2π (-Z) | (-R, 0) | π | 後進 |
| 4 | +2π (+Z) | (-R, 0) | π/2 | **前進**（左回り） |
| 5 | -2π (-Z) | (R, 0) | π/2 | **前進 + 右回り** ✓ |

### 原因

**このプロジェクトで使用しているGLB車モデルは、+Y方向を「前方」としてインポートされる。**

```
        +Y (前方 ← 車のデフォルト向き)
         ↑
         |
---------+--------→ +X (右)
         |
         ↓
        -Y (後方)
```

### Empty回転と車の移動方向の関係

EmptyがZ軸負方向（時計回り）に回転すると、車の配置位置によって移動方向が変わる:

| 車の配置位置 | Emptyの-Z回転での移動方向 |
|-------------|------------------------|
| (-R, 0) | -Y方向 |
| (0, R) | +X方向 |
| **(R, 0)** | **+Y方向** ← 正解 |
| (0, -R) | -X方向 |

### 解決策

車の配置位置を **(R, 0)** に変更し、Z回転を **π/2** に設定することで:
- Emptyの-Z回転（時計回り）で車は+Y方向に移動
- 車の前方が+Y方向なので、移動方向と進行方向が一致 → **前進 + 右回り**

```python
# 正しい実装
turn_center = (car_pos[0] - turning_radius, car_pos[1], car_pos[2])  # 車の左側に回転中心
empty.location = turn_center
car.parent = empty
car.location = (turning_radius, 0.0, 0.0)  # Emptyの右側に配置
car.rotation_euler = (0.0, 0.0, math.pi / 2)  # +Y方向を向く

# Emptyの-Z回転で右回り1週
total_angle = -2.0 * math.pi  # -360度（時計回り）
```

## 参考: Blenderの座標系

- **X軸**: 右方向（正）/ 左方向（負）
- **Y軸**: 前方（正）/ 後方（負）← このプロジェクトのGLBモデルでは+Yが前方
- **Z軸**: 上方向（正）/ 下方向（負）

## 注意事項

1. GLBモデルによってデフォルト向きが異なる可能性があるため、他のモデルを使用する場合は必ず確認すること
2. Empty親オブジェクト手法を使用する場合、車の既存アニメーションデータを完全にクリアしてから設定すること
3. 親子関係を設定する前に `bpy.context.view_layer.objects.active` をEmptyに設定すること
4. **右回り（時計回り）にするには**: Emptyを-Z回転し、車を(R, 0)に配置して+Y方向を向ける
5. **左回り（反時計回り）にするには**: Emptyを+Z回転し、車を(-R, 0)に配置して+Y方向を向ける
