shortAnimal仕様.md

  動物ショート動画の構成

  カメラの高さは、基本100cm（円軌道中）。
  カット1/1-2ではZ=0.5m開始、カット2ではZ=7m開始→1m下降。
  カメラの動き、視点の動きは、常になめらかにつながるように。
  ゆっくりになってもいいので、カメラの動きが止まらないように調整する。
  カメラが止まるのはNG！

  Humanの位置：x：２m、y：-4m
  Humanの色：グレー


  １：
  ３秒間（fr0-72） すでに重なっている状態
     動物はすべて不透明
     カメラ位置：X:１ｍ,Y:-８ｍ,Z:０．５ｍ で静止
     カメラの向き：斜め上２０度向いた状態から、動物Bの一番高いところにゆっくり視点を移動する

  １ー２：
  ６秒間（fr72-216） 重なっている状態
     動物Ｂが半透明（瞬時に一定透明度0.35に切り替え。グラデーション遷移はしない）
     カメラ位置：
       X:１ｍ,Y:-８ｍ,Z:０．５ｍ（開始）
       → X:１ｍ,Y:-８．５ｍ,Z:２．７５ｍ（中間/fr144）
       → X:１ｍ,Y:-９ｍ,Z:７ｍ（终了）
     カメラの向き：動物Bの最高部から、max(动物A,B)の高さの75%に視点をゆっくり移動する

  ２：
  ６秒間（fr216-360） ２つのモデルが横へスライドして、2体が並ぶ
     始めは半透明で、完全に分かれた状態で、不透明にする（瞬時に不透明に戻す）
     カメラ位置：X:１ｍ,Y:-９ｍ,Z:７ｍ → X:１ｍ,Y:-９ｍ,Z:１ｍ
     カメラの向き：max(动物A,B)の高さの75%を向く（高位維持）

  ３：
  25秒間（fr360-960） 両方の動物を視界に入れながら、円軌道で回りを１週する
     軌道の始点はカット2終了時のカメラ位置と一致し、そこから滑らかに接続する。
     半径は ９m を使用し、始点角度もその前に合わせる。
     カメラの向き：max(动物A,B)の高さの75%を向く（高位維持）

  ４：
  ３秒間（fr960-1032） カメラはゆっくり正面に戻ってくる
     （最後に動物を重ねるのは不要。動物は動かなくていい）


   ## カメラ・視点の連続性ルール（重要）

   **各カット間のカメラ位置とターゲットは滑らかに接続する。**

   - カット2終了位置 (1, -9, 1) からカット3の円軌道が開始される
   - 軌道半径/始点角度は前のカット終了位置に一致させる（瞬間移動禁止）

   **ターゲットZの変化フロー（ジャンプなし・高視点）:**

   | フレーム | ターゲットZ値 | 说明 |
   |---|---|---|
   | fr0 | `initial_target_z` (斜め上20度) | 初期値 |
   | fr72 | `animal_b_max_z` | 动物B最高部 |
   | fr216 | `max(animalA, animalB) * 0.75` | 高位化、见切れ防止 |
   | fr360-960 | `max(animalA, animalB) * 0.75` | 高位维持（円軌道中） |
   | fr960-1032 | `max(animalA, animalB) * 0.75` | 高位维持（正面回归） |

   **カメラ位置の流れ:**

   | カット | カメラ位置 | 状态 |
   |---|---|---|
   | カット1 | (1, -8, 0.5) 固定 | 静止 |
   | カット1-2 | (1,-8,0.5)→(1,-8.5,2.75)→(1,-9,7) | 3段階上昇 |
   | カット2 | (1,-9,7)→(1,-9,1) | Z下降 |
   | カット3 | (1,-9,1) から円軌道半径9m | 1周回転 |
   | カット4 | 円軌道终了位置→(2,-5,1.0) | 正面回归 |

   ## 半透明化のルール（重要）

   **动物Bの半透明化は「瞬時の切り替え」で行う。**

   - fr72: alphaを **即座に0.35** に変更する（グラデーション遷移禁止）
   - fr360: alphaを **即座に1.0** に戻す（完全分離時に不透明化）

   | フレーム範囲 | Alpha値 | 状态 |
   |---|---|---|
   | fr0-72 | 1.0 | 不透明 |
   | fr72-360 | 0.35 | 半透明 |
   | fr360-1032 | 1.0 | 不透明 |

   **禁止事項:**
   - clamp() や漸进的な式で透明度を徐々に変化させてはいけない
   - fr72など切り替えフレームの直後に暗くなる現象が起こらないようにすること
   - 透明度は常に「不透明(1.0)」か「半透明(0.35)」の2つの值の間で瞬時に行き来するだけ
