# 全長差表示テキストの位置修正計画

## 問題概要

**発生状況**: シーン 5 とシーン 6 の両方で、全長差表示テキストが地面に張り付いた状態になっている。

**期待動作**: テキストは車の真上に表示され、カメラから見て明確に見えるべきである。

## 原因分析

現在のコード (`animation_settings_cut2.py` 行 318) では：
```python
text_container.location = (avg_center_x, avg_center_y - 0.3, max_height + 1.5)
```

この計算が正しく機能していない可能性：
1. `max_height` の計算 (`get_car_max_z()`) がバウンディングボックスから取得するが、車の形状や位置によって期待通りの値が得られない
2. カメラ移動中（シーン 6）にテキストの位置が追従していない

## 修正方針

**基本戦略**: テキストを地面からの絶対的な高さに固定し、常に明確に見えるようにする。

### 具体的な変更点

1. **Z 座標の固定化**
   - 現在の `max_height + 1.5` から `3.0` に変更
   - これにより、車の高さに関係なく常に地面から 3m の高さに表示される

2. **Y 座標の微調整**
   - `avg_center_y - 0.3` を維持（車体の中央やや手前）
   - X 座標は `avg_center_x` で中央配置

## 修正対象ファイル

- [`animation_settings_cut2.py`](../animation_settings_cut2.py:318)

## 修正コード

```python
# コンテナの位置と回転を設定（文字がカメラに向くように）
# 地面からの絶対的な高さを確保し、常に明確に見えるように配置
text_container.location = (avg_center_x, avg_center_y - 0.3, 3.0)
```

## 検証方法

1. Blender でシーンを再生し、シーン 5 と 6 の両方でテキストが車の真上に表示されるか確認
2. カメラ移動中（シーン 6）にテキストの位置が安定しているか確認
3. テキストが地面に埋もれたり、車体に重なったりしないか確認

## 期待効果

- シーン 5: テキストが常に車の真上に表示され、明確に見える
- シーン 6: カメラ移動中もテキストの位置が安定し、消えたり動いたりしない
- 全体的に視認性が向上し、全長差比較が明確になる
