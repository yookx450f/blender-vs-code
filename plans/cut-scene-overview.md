# カット・シーン一覧

> **最終更新**: 2026-08-16
> このドキュメントはアニメーションの全体構成をまとめたものです。
> アニメーション設定を変更した場合は、本ドキュメントも合わせて更新してください。

## 基本情報

| 項目 | 値 |
|------|-----|
| 総フレーム数 | 0 - 2880 |
| フレームレート | 24 fps |
| 総再生時間 | 120秒（2分） |
| アスペクト比 | 16:9（横長） |

## カット構成一覧

| カット | フレーム範囲 | 秒数 | シーン | 概要 |
|--------|-------------|------|--------|------|
| カット1 | 0 - 696 | 29秒 | シーン1-4 | 車の出現・中央集合・カメラアングル変更 |
| カット2 | 696 - 1272 | 24秒 | シーン5-7 | 全長差・横幅差の表示 |
| カット3 | 1272 - 1632 | 15秒 | シーン8-9 | 最低地上高差の表示 |
| カット4 | 1632 - 2256 | 26秒 | シーン10-12 | 最小回転半径のデモ |
| カット5 | 2256 - 2880 | 22秒 | シーン13-14 | フェードアウト・走り去る |
| **合計** | **0 - 2880** | **120秒** | **シーン1-14** | |

## シーン詳細

### カット1（フレーム 0 - 696 / 29秒）

| シーン | フレーム範囲 | 秒数 | 内容 | カメラ位置 |
|--------|-------------|------|------|-----------|
| シーン1 | 0 - 96 | 4秒 | 車の出現・中央への集合（CarB半透明化開始） | (6.5, -6.5, 4.0) 斜め上固定 |
| 停止 | 96 - 144 | 2秒 | 静止 | 同上 |
| シーン2 | 144 - 264 | 5秒 | カメラがトップビューに移動 | (0.0, 0.0, 14.0) 真上 |
| 停止 | 264 - 312 | 2秒 | 静止 | 同上 |
| シーン3 | 312 - 408 | 4秒 | カメラがZ軸90度回転（車が横に） | (0.0, 0.0, 14.0) 真上→回転 |
| 停止 | 408 - 456 | 2秒 | 静止 | 同上 |
| シーン4 | 456 - 648 | 8秒 | カメラがサイドビューに移動 | (8.0, 0.0, 2.5) 横から |
| 停止 | 648 - 696 | 2秒 | 静止 | 同上 |

**対応ファイル**: [`animation_settings_cut1.py`](animation_settings_cut1.py)

## 各シーンの演出まとめ

| シーン | 比較項目 | 表示形式 |
|--------|---------|---------|
| シーン1-4 | - | 車の出現・カメラアングル変更（導入） |
| シーン5 | 全長差 | サイドビュー + テキストアニメーション |
| シーン6 | - | カメラ移動（サイド→正面） |
| シーン7 | 横幅差 | 正面ビュー + テキストアニメーション |
| シーン8 | - | カメラ移動（正面→左側低位置） |
| シーン9 | 最低地上高差 | 低アングル + テキスト表示 |
| シーン10 | - | 横並び配置・不透明化 |
| シーン11 | 最小回転半径 | 実際の回転デモ（軌跡付き） |
| シーン12 | 最小回転半径 | 比較式テキスト表示 |
| シーン13 | - | フェードアウト・車分離 |
| シーン14 | 加速性能 | 走り去るアニメーション + 加速時間テキスト |

## 実行コマンド

```bash
# 全カット実行
python run.py

# 単一カット実行
python run.py 1    # カット1のみ
python run.py 2    # カット2のみ
python run.py 3    # カット3のみ
python run.py 4    # カット4のみ
python run.py 5    # カット5のみ
python run.py short  # ショート動画

# レンダリング実行
python run.py --render
```
