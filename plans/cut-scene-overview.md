## シーン詳細

### カット1（フレーム 0 - 576 / 24秒）

> **【改訂: 離脱率改善】** 停止シーンをすべて削除し、カメラは常に動くように変更。
> トップビューの高さを14m→8mに低下させ、車をアップで捉える演出を追加。
> **フレーム配置を再調整** + **BEZIER interpolation** でシーン間の接続を滑らかにする。

| シーン | フレーム範囲 | 秒数 | 内容 | カメラ位置 |
|--------|-------------|------|------|-----------|
| シーン1 | 0 - 30 | 1.25秒 | 車の出現・カメラゆっくり右回り接近 | (6.5, -6.5, 4.0) → (6.0, -5.5, 3.8) |
| シーン1 | 30 - 96 | 2.75秒 | 中央集合・カメラ軌道継続（CarB半透明化） | (6.0, -5.5, 3.8) → (5.5, -3.5, 3.5) |
| シーン2 | 96 - 144 | 2秒 | カメラ右回りながら上方へ昇る | (5.5, -3.5, 3.5) → (4.5, -2.0, 5.0) |
| シーン2 | 144 - 264 | 5秒 | トップビュー到達（高さを8mに低下） | (4.5, -2.0, 5.0) → (3.0, -1.0, 8.0) |
| シーン3 | 264 - 312 | 2秒 | 回転加速・前方へ降りてくる | (3.0, -1.0, 8.0) → (3.5, 0.5, 7.0) |
| シーン3 | 312 - 408 | 4秒 | 斜め前へ降りてくる（Z軸回転継続） | (3.5, 0.5, 7.0) → (5.0, 1.0, 5.5) |
| シーン4 | 408 - 456 | 2秒 | サイドビューに接近 | (5.0, 1.0, 5.5) → (6.5, 0.5, 3.5) |
| シーン4 | 456 - 528 | 3秒 | サイドビュー軌道継続 | (6.5, 0.5, 3.5) → (7.5, 0.0, 2.8) |
| 新シーン | 528 - 552 | 1秒 | 車アップ・スローパン | (7.5, 0.0, 2.8) → (7.8, 0.0, 2.6) |
| 接続 | 552 - 576 | 1秒 | カット2接続位置に到達 | (7.8, 0.0, 2.6) → (8.0, 0.0, 2.5) |

**対応ファイル**: [`animation_settings_cut1.py`](animation_settings_cut1.py)

## 各シーンの演出まとめ

| シーン | 比較項目 | 表示形式 |
|--------|---------|---------|
| シーン1-4 | - | 車の出現・カメラアングル変更（導入） |
| シーン5 | 全長差 | サイドビュー + テキストアニメーション |
| シーン6 | - | カメラ移動（サイド→正面） |
| シーン7 | 横幅差 | 正面ビュー + テキストアニメーション |
| シーン8 | - | カメラ移動（正面→左側低位置） |
| シーン9 | 最低地上高差 | 低アングル + テキスト表示 |
| シーン10 | - | 横並び配置・不透明化 |
| シーン11 | 最小回転半径 | 実際の回転デモ（軌跡付き） |
| シーン12 | 最小回転半径 | 比較式テキスト表示 |
| シーン13 | - | 軌跡・比較式テキストのフェードアウト |
| シーン14 | - | フェードアウト・車分離 |
| シーン15 | 加速性能 | 走り去るアニメーション + 加速時間テキスト |

## 実行コマンド

```bash
# 全カット実行
python run.py

# 単一カット実行
python run.py 1    # カット1のみ
python run.py 2    # カット2のみ
python run.py 3    # カット3のみ
python run.py 4    # カット4のみ
python run.py 5    # カット5のみ
python run.py short  # ショート動画

# レンダリング実行
python run.py --render
```
