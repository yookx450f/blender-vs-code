# short-s アニメーション動作ドキュメント

## 1. 概要

`short-s` は、縦長 9:16 フォーマット（1080x1920）のショート動画用アニメーションモードです。

2台の車を横並びで配置し、Y負方向（画面奥）へ加速して走り去る単一シーンのアニメーションを生成します。

| 項目 | 値 |
|------|-----|
| ソースファイル | [`animation_settings_short_s.py`](animation_settings_short_s.py) |
| 呼び出し元 | [`blend_scene_creator.py`](blend_scene_creator.py:1182) |
| 実行コマンド | `python run.py short-s` |
| フレーム範囲 | 0 - 480（約20秒、24fps） |
| アスペクト比 | 9:16（縦長） |
| 出力ファイル | `short_s_scene.blend` |

## 2. 実行フロー

### 2.1 エントリポイント

[`run.py`](run.py:39) で `short-s` が定義され、環境変数 `CUT_NUMBER=short-s` として Blender に渡されます。

```
python run.py short-s
```

### 2.2 blend_scene_creator.py での処理

[`blend_scene_creator.py`](blend_scene_creator.py:1182) の `main()` 関数内で、以下の順で処理されます：

1. **シーン初期化** - `clear_scene()` で既存オブジェクトを削除
2. **GLBインポート** - `cars_config.json` から指定された2台の車をロード
3. **接地処理** - 床面（Y=0）に車を配置
4. **カメラ設定** - 縦長用に斜め上からの俯瞰角度に配置
5. **アニメーション設定** - `setup_short_s_animations()` を呼び出し
6. **シーン保存** - `short_s_scene.blend` として保存

### 2.3 加速データのパラメータ渡し

[`blend_scene_creator.py:1184-1198`](blend_scene_creator.py:1184) で、各車の寸法情報と加速時間を辞書として抽出し、 `setup_short_s_animations()` に渡します：

```python
car_dimensions_short_s = {
    "carA": {
        "length": ...,
        "width": ...,
        "height": ...,
        "ground_clearance": ...,
        "turning_radius": ...,
        "acceleration_0_to_100_km_h": ...  # JSONから取得（例: 9.4秒）
    },
    "carB": { ... }
}
```

## 3. アニメーション詳細

### 3.1 シーン構成

| 要素 | 仕様 |
|------|------|
| シーン数 | 1シーンのみ |
| 開始フレーム | 0 |
| 終了フレーム | 480（約20秒） |
| 車Aの開始位置 | X=-1.5, Y=rear_offset_y, Z=接地Z |
| 車Bの開始位置 | X=+1.5, Y=0.0, Z=接地Z |
| 車の向き | Y負方向へ（-Z回転で -π/2） |

### 3.2 カメラ設定

| 項目 | 値 |
|------|-----|
| 位置 | (0.0, -8.0, 10.0) - 固定 |
| 注視点（開始時） | (0.0, 0.0, 1.0) |
| レンズ焦距 | 35mm（縦長用に広角化） |

カメラは位置固定で、回転のみで車を追います。

### 3.3 加速アニメーションの計算

各車の `acceleration_0_to_100_km_h`（0-100km/h加速時間）に基づいて、物理的に正しい加速カーブを生成します。

#### 計算式

```
加速度 (m/s²) = (100 / 3.6) / 加速時間
到達速度 (m/s) = 加速度 × 動画の総秒数
移動距離 = 加速度 × (総秒数の4乗) / (4 × 総秒数の3乗) × 総秒数
```

#### イージングカーブ

`t³` の ease-in カーブを適用し、実車の発進のようにゆっくり加速し、徐々に速度を上げる動きを実現します。

```python
def ease_in_acceleration(t):
    return t ** 3
```

#### キーフレーム密度

50ステップ（51キーフレーム）で滑らかなアニメーションを生成します。

### 3.4 カメラ注視点の追従

カメラは位置固定ですが、回転のみで車の動きを追います：

| 時間帯 | 注視点の挙動 |
|--------|-------------|
| 前半（t < 0.5） | 車の位置の少し手前（Y-3.0, Z=1.0） |
| 後半（t >= 0.5） | 徐々に遠くへ・点がなる方向へ（Yはさらに負方向、Zは低下） |

### 3.5 ライトシステム

各車に個別のエリアライトをペアレント設定し、車がどこに行っても明るく照らされます。

| プロパティ | CarA_Light | CarB_Light |
|-----------|------------|------------|
| タイプ | AREA | AREA |
| エネルギー | 200 | 200 |
| サイズ | 3 | 3 |
| 相対位置 | (0, 0, 3) - 車の真上 | (0, 0, 3) - 車の真上 |
| 回転 | (-π/4, 0, 0) | (-π/4, 0, 0) |

## 4. 初期化処理

アニメーション設定前に、以下のクリーンアップ処理が実行されます：

1. **アニメーションデータクリア** - 車の既存のアニメーションデータを削除
2. **Empty親オブジェクト解除** - 回転ピボット用のEmptyを削除
3. **親子関係解除** - 車の親をNoneにリセット

## 5. 戻り値

[`CutState`](animation_common.py:16) オブジェクトを返し、以下の最終状態を保持します：

| プロパティ | 内容 |
|-----------|------|
| `car_a_loc` | CarAの最終位置 (x, y, z) |
| `car_b_loc` | CarBの最終位置 (x, y, z) |
| `camera_loc` | カメラの最終位置 |
| `camera_rot` | カメラの最終回転 (euler) |

## 6. short-s の特徴（他のモードとの違い）

| 特徴 | short-s | short / short2 | 通常カット |
|------|---------|---------------|-----------|
| フォーマット | 縦長9:16 | 縦長9:16 | 横型16:9 |
| シーン数 | 1シーン | 1-2シーン | 複数シーン |
| 加速時間テキスト | なし | なし | あり |
| CarB半透明化 | なし | あり（short2） | あり |
| 加速カーブ | ease-in (t³) | - | - |
| 物理ベース加速 | ✓（JSONデータ使用） | ✗ | ✗ |
