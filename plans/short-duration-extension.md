# Short動画時間を1秒延長する計画

## 概要
`animation_settings_short.py` のアニメーション長を **8秒(192フレーム) → 9秒(216フレーム)** に延長する。

## 変更箇所

### 1. ファイルヘッダーコメント（3行目）
- `フレーム 0-192（約8秒、24fps）` → `フレーム 0-216（約9秒、24fps）`

### 2. 関数ドキュメント（211行目）
- `フレーム 0-144、約6秒` → `フレーム 0-216、約9秒`

### 3. カメラ回転計算（289-290行目）
```python
# 現在
total_rotation = -0.85 * (192 / 144)
# 変更後
total_rotation = -0.85 * (216 / 144)
```

### 4. キーフレーム間隔（307-308行目）
```python
# 現在
arc_keyframes = [0, 24, 48, 72, 96, 120, 144, 168, 192]
# 変更後
arc_keyframes = [0, 24, 48, 72, 96, 120, 144, 168, 192, 216]
```

### 5. 車の位置維持キーフレーム（335-339行目）
フレーム 192 の後に フレーム 216 のキーフレームを追加：
```python
_set_location_keyframe(car_a, 216, car_a_end[0], car_a_end[1], car_a_end[2])
_set_location_keyframe(car_b, 216, car_b_end[0], car_b_end[1], car_b_end[2])
```

### 6. CarBの透明度設定（354-363行目）
最後のフレームを 192 → 216 に変更：
```python
(216, 0.35),  # 最終: 透明度維持
```

### 7. 最終フレームコメント（347行目）
- `[フレーム 192]` → `[フレーム 216]`

### 8. Alphaコメント（365行目）
- `フレーム0-192` → `フレーム0-216`

## 影響範囲
- `animation_settings_short.py` のみ
- 他のカット設定ファイルには影響なし
