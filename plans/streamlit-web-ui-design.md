# Streamlit 車種Web管理画面設計

## 概要

既存の `cars.db` (SQLite) をバックエンドに使用し、ブラウザから車種データを直感的に管理できるWeb UIを提供する。

---

## 1. 技術スタック

| 項目 | 選択 |
|------|------|
| フレームワーク | Streamlit |
| データベース | SQLite (既存の `cars.db`) |
| テーブル表示 | pandas DataFrame + st.dataframe |
| 起動方法 | `python web_manage_cars.py` → http://localhost:8501 |

## 3. 機能仕様

### 3.1 車種一覧表示

- `st.dataframe` で全車種をテーブル表示
- 検索ボックスで車名部分一致フィルタ
- クリックで選択行のIDを取得（編集・削除用）

### 3.2 新規追加

- フォーム入力 → DB INSERT
- GLBファイル名の重複チェック
- 成功/失敗メッセージ表示

### 3.3 編集

- テーブルから車種を選択（またはID入力）→ 現在値をフォームに自動入力
- 変更後の保存 → DB UPDATE
- 未変更フィールドはそのまま維持

### 3.4 削除

- 選択行の確認ダイアログ → DB DELETE
- 削除前に車名表示で確認

### 3.5 CSVエクスポート

- 全データをCSVにエクスポート（バックアップ用）

## 5. 実装計画

### 5.1 ファイル構成

```
blender-vs-code/
├── web_manage_cars.py   # Streamlit Web管理画面 (新規)
├── cars.db              # SQLiteデータベース (既存)
└── manage_cars.py       # CLIツール (既存、変更なし)
```

### 5.2 実装ステップ

| 順 | タスク | 内容 |
|----|--------|------|
| 1 | Streamlit依存関係の確認 | `pip install streamlit pandas` |
| 2 | DB接続モジュールの共通化 | `manage_cars.py` のDB関数を再利用、またはインポート |
| 3 | 一覧表示 + 検索機能 | st.dataframe + st.text_input |
| 4 | 新規追加フォーム | st.form + st.text_input/st.number_input |
| 5 | 編集フォーム | 選択行のデータ読み込み → 更新 |
| 6 | 削除機能 | st.button + 確認ダイアログ |
| 7 | CSVエクスポート | st.download_button |
| 8 | 動作確認 | `python web_manage_cars.py` でブラウザ起動 |

## 6. 注意事項

- Streamlitはローカル開発用であり、外部公開しない
- DBファイルは `.gitignore` で除外済み
- 既存の `blend_scene_creator.py` との互換性は維持（DBスキーマ変更なし）
