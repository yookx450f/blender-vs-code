# Blender x LLM 自動車比較動画自動化システム - 開発ルール

## 1. システムの概要とゴール
- 本プロジェクトは、車の3Dモデル（GLB）と主要諸元データを読み込み、Blenderを使用して「サイバー空間×単色クレイモデル」の動画を全自動で生成するPythonパイプラインです。
- YouTubeチャンネル「Car Diff 〜車の比較〜」向けの、BGMとテロップで魅せるクールな3〜5分の横型動画（16:9）の量産を目的とします。

## 2. 開発環境・技術スタック
- OS: Windows 10
- Editor: VS Code (with Blender Development extension)
- 3D Software: Blender 5.2+ (Python API: `bpy`)
- LLM / Agent: Ollama (qwen3.6:35b) & Roo Code / Cline

## 3. Blender Python (`bpy`) 記述ルール
- **コンテキストの保護**: `bpy.context.active_object` などを過信せず、オブジェクトの選択や操作は可能な限り名前（`bpy.data.objects[...]`）で直接指定すること。
- **演算子（ops）の最小化**: `bpy.ops` は動作が重くエラーの原因になりやすいため、可能な限り `bpy.data` や `object.location` などのデータAPIを直接書き換えるアプローチを優先すること。
- **オブジェクトのクリーンアップ**: スクリプトの実行開始時に、古いテスト用オブジェクトやライト、マテリアルを完全に削除する初期化関数（`clear_scene()`）を必ず含めること。
- **エラーハンドリング**: ファイルの読み込み（GLBなど）やモディファイアの適用時は、対象が存在しない場合のエラー落ちを防ぐ条件分岐を入れること。

## 4. ビジュアル・演出の共通仕様
- **背景/世界観**: 真っ黒な背景に、ネオンブルー/シアン、またはオレンジに発光（エミッション）する3Dグリッド（床面）を配置する。
- **マテリアル**: 車の3Dモデルはテクスチャを捨て、単色（クレイモデル調）に統一する。粗さ（Roughness）は0.4〜0.5に設定し、ライティングの反射でボディラインを際立たせる。
- **車種識別**: 2台の比較車両が混同しないよう、それぞれの足元に光るリング（車種名付きの3Dテキストまたは色分けされた台座）を追従させる仕様にする。

## 5. 生成コードへの要望
- 生成するスクリプトは、上部に「車種名、全長、全幅、全高、GLBファイルへのパス」を変数として定義し、そこを書き換えるだけで他の車種にも使い回せる「テンプレート構造」にすること。
